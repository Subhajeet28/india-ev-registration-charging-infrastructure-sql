# Project Presentation

[**View the 13-slide presentation (PDF)**](India_EV_Infra_SQL_Portfolio.pdf)

The presentation covers eight analytical questions on state-wise EV registrations (2021–2025) and a 2025 public charging-station snapshot. It includes query screenshots, outputs and key takeaways.

**Context:** The underlying raw datasets and precise charging snapshot date are not yet documented in this repository. The PDF reports the analysis results but is not a substitute for source data or independent validation.

**Interpretation:** Registrations per station is a comparative ratio, not a measurement of charger utilization or proof of charging capacity shortages.
